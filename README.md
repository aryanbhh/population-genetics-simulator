# population-genetics-simulator
### v1.0
Simulate the frequency of a trait and how it changes across generations in a population. 

# What it does
Creates a population of individuals, each carrying two alleles. Across generations, individuals reproduce by randomly selecting two parents. Each offspring inherits one allele from each parent. The frequency of a selected allele is tracked throughout the simulation and the results are visualized using Matplotlib.

# Features
- Creates a population of individuals with two alleles each
- Simulates reproduction across multiple generations
- Randomly selects parents for each offspring
- Imitates inheritance by passing one allele from each parent to the offspring
- Tracks allele frequencies over a given time
- Visualizes genetic drift with a Matplotlib graph
